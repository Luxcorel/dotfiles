# Global AGENTS.md

## General

- Early returns instead of nested if statements where reasonable.
- When adding guard clauses after an operation, put the if-statement directly below.

- Prefer being direct over being conversational.

## Git

- Use Conventional Commits.

## TypeScript

- Use pnpm.
- Never allow pre or post-install scripts.
- Use the Impeccable skill for UI when relevant.
- Don't use pnpm --store-dir. In case of issues ask for permission to run pnpm add.

## For non-repo chats

- Use the sandbox directory at ~/repos/vibe/sandbox/
